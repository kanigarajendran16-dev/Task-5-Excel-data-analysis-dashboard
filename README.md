# 📊 Excel Data Analysis Dashboard

## 📌 Project Overview

This project is an **Excel Data Analysis Dashboard** created to analyze sales data and present meaningful business insights through formulas, PivotTables, KPIs, charts, and interactive filters.

The dashboard helps users understand **sales performance, profit, orders, quantity, regions, categories, and monthly trends** in an easy-to-understand visual format.

---

## 🎯 Objectives

* Clean and organize raw sales data
* Perform data analysis using Excel formulas
* Use sorting and filtering for better data exploration
* Create PivotTables for summarizing data
* Calculate important Key Performance Indicators (KPIs)
* Create charts and visualizations
* Build an interactive dashboard
* Analyze data using Region, Category, and Month filters
* Identify important business findings

## 🎛️ Interactive Dashboard

The dashboard provides interactive dropdown filters.

### Available Filters

* **Region**
* **Category**
* **Month**

Users can select different combinations of filters to analyze specific parts of the dataset.

For example:

```text
Region → South
Category → Technology
Month → January
```

The dashboard automatically updates the displayed KPIs, tables, and charts based on the selected filters.

## 🚀 How to Use

### Excel Version

1. Open the Excel workbook.
2. Go to the **Raw Data** sheet.
3. Review the prepared data.
4. Open the **Working/Data Analysis** sheet.
5. Check formulas and calculations.
6. Open the **Summary** sheet.
7. Review PivotTables and KPIs.
8. Open the **Dashboard** sheet.
9. Use the available filters and charts.

### Interactive HTML Dashboard

1. Open `Final_Interactive_Excel_Dashboard.html`.
2. Select a **Region**.
3. Select a **Category**.
4. Select a **Month**.
5. Review the updated KPIs and charts.
